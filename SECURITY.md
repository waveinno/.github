# Security Policy

Security is an important part of the software we build and maintain.

## Reporting a Vulnerability

If you discover a potential security vulnerability in a Waveinno open-source project, please do not disclose the vulnerability publicly through GitHub Issues or discussions.

Instead, contact the Waveinno team privately with:

* A description of the vulnerability
* The affected repository and version
* Steps to reproduce the issue
* Potential impact
* Any relevant proof of concept

## Responsible Disclosure

Please allow reasonable time for the Waveinno team to investigate and address reported security issues before publicly disclosing the vulnerability.

We appreciate responsible security research and collaboration.

## Security Best Practices

Contributors should never commit:

* Passwords
* API keys
* Access tokens
* Private keys
* Cloud credentials
* Database credentials
* Other sensitive information

Use environment variables or appropriate secret-management systems instead.
