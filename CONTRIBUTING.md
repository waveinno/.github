# Contributing to WAVEINNO

Thank you for your interest in contributing to Waveinno open-source projects.

We welcome developers, engineers, and contributors who want to improve our tools, libraries, documentation, and engineering resources.

## Before Contributing

Please:

* Read the repository README.
* Check existing issues and pull requests.
* Search for existing discussions before opening a new issue.
* Follow the coding and documentation conventions of the project.
* Keep changes focused and easy to review.

## Pull Requests

When submitting a pull request:

1. Clearly describe what you changed.
2. Explain why the change is needed.
3. Include relevant tests where applicable.
4. Update documentation when necessary.
5. Keep commits and changes focused on the purpose of the pull request.

## Issues

Before opening an issue, please make sure the issue has not already been reported.

Include enough information for the maintainers to reproduce and understand the problem.

## Code Quality

Contributions should prioritize:

* Readability
* Maintainability
* Security
* Performance
* Testability
* Clear documentation

## Respectful Collaboration

We expect all contributors to communicate respectfully and constructively.

Thank you for helping us build better open-source software.
